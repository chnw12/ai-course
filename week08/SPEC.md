# 주차 요금 계산 시스템 요구사항 명세서 (Specification)

## 1. 시스템 개요
본 시스템은 차량의 입차 및 출차 시각을 입력받아 주차 요금을 자동으로 계산하고, 결제 내역을 목록으로 관리하며, 등록된 차량 정보를 관리할 수 있는 주차 관리 프로그램이다.

## 2. 핵심 비즈니스 로직 (요금 산정 규칙)

### 2.1 기본 요금 규칙
- **무료 구간**: 주차 시간 중 처음 **30분**은 무료이다.
- **추가 요금**: 30분 초과 시, **10분 단위로 500원**씩 부과된다.
- **올림 처리**: 10분 단위 미만의 잔여 시간(예: 1분, 5분 등)도 10분으로 간주하여 요금을 부과한다.
- **최대 요금**: 1일(24시간) 최대 요금은 **20,000원**으로 제한한다.

### 2.2 특이 사항 (야간 무료 정책)
- **야간 무료 시간대**: **18:00부터 다음 날 06:00까지** 사이에 출차하는 경우, 해당 차량의 주차 요금은 **0원(무료)**으로 처리한다.

### 2.3 요금 표시 규칙
- 모든 금액은 천 단위마다 콤마(`,`)를 포함하여 표시한다. (예: `15,000원`)

---

## 3. 기능 요구사항

### 3.1 메인 화면 (요금 계산 및 목록)
- **입력 기능**: 입차 시각 및 출차 시각을 `HH:MM` (24시간제) 형식으로 입력받는다.
- **계산 및 추가**: 입력된 시각을 바탕으로 요금을 계산하여 목록에 추가한다.
- **목록 표시**: [입차 시각, 출차 시각, 주차 시간, 요금]을 포함한 리스트를 보여준다.
- **목록 관리**: 각 항목 옆에 '삭제' 버튼을 배치한다. 삭제 시 해당 항목이 제거되며, 화면 하단의 '오늘의 총 합계'가 실시간으로 재계산된다.
- **총 합계**: 오늘 발생한 모든 결제 금액의 합계를 화면에 상시 표시한다.



## 4. 테스트 케이스 (Test Cases)

| ID | 입력 (입차/출차) | 기대 결과 (요금) | 테스트 목적 |
|:---|:---|:---|:---|
| TC-01 | 09:00 / 09:20 | 0원 | 30분 이내 무료 확인 |
| TC-02 | 09:00 / 09:30 | 0원 | 30분 경계값 확인 |
| TC-03 | 09:00 / 09:31 | 500원 | 30분 초과 시 10분 단위 부과 확인 |
| TC-04 | 09:00 / 10:00 | 2,500원 | 60분 주차 시 (30분 무료 + 30분 유료) 확인 |
| TC-05 | 17:00 / 18:30 | 0원 | 18시 이후 출차 시 야간 무료 적용 확인 |
| TC-06 | 05:00 / 06:00 | 0원 | 06시 이전 출차 시 야간 무료 적용 확인 |
| TC-07 | 09:00 / 15:00 | 20,000원 | 최대 요금(2만원) 제한 확인 |
| TC-08 | 10:00 / 10:45 | 1,500원 | 45분 주차 (30분 무료 + 15분 -> 20분 부과) 확인 |

요구사항
시각은 09:30처럼 24시간제 "시:분"으로 입력한다. 출차는 입차보다 뒤여야 한다.
요금은 30분까지 무료, 이후 10분마다 500원이다. 10분이 안 되는 나머지도 10분으로 센다. 하루 최대 요금은 20,000원이다.
계산할 때마다 입차, 출차, 주차 시간, 요금을 목록에 쌓는다. 목록의 각 줄에는 삭제 버튼이 있고, 지우면 합계를 다시 계산한다.
금액은 천 단위마다 쉼표를 넣어 보여 준다.
18시부터 다음날 06시까지는 출차시 무료이다.
